# Sample: Lakeshore Tourism · Project Management Demo (fictional)

A content-operations team runs its annual travel guide, campaigns and events in the free **PMT** app (Salesforce Labs) on the same platform as its sponsorship pipeline. The persona is **Cal Rogers**, Content Operations Manager. All names and records are fictional demo data.

- `demo.json`: the config (31 steps, 17 movie scenes)
- `lakeshore-pm-preflight.html`: the built page. Open it to try every feature.

Rebuild it: `python3 scripts/build.py examples/lakeshore-pm/demo.json -o examples/lakeshore-pm/lakeshore-pm-preflight.html`
